## Colab / GitHub Workflow

1. Click an **Open In Colab** badge above (or in Colab: **File -> Open notebook -> GitHub -> `Sal-Faris/mech-interp-mini-projects`**).
2. Switch runtime to **T4 GPU** (for `gpt2`) or **L4 / A100** (for 2B+ models).
3. Save progress back to GitHub anytime with **File -> Save a copy in GitHub** (keep the same repo and file path).
4. Locally, run `git pull` to bring Colab changes down to your machine.
